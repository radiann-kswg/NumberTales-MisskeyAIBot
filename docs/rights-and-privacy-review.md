## 問題なしと判断したもの

- **創作 DB（CC BY-NC 4.0）の利用**: Bot は DB をプロンプト参照に使うだけで学習・再配布はしない。著作者本人の非営利運用であり、`third-party-policy.md` 3.2 の条件にも適合。第三者がフォークして運用する場合は非営利＋出典表記が条件になる（README に一言追記）。
- **PenchantManufacture_ImagePipeline（CC BY 4.0）**: 生成 PNG にクレジットが埋め込まれ、プロフィールにも固定表示。`uploadFile` の alt にはプレーン式が入る。
- **npm 依存**: misskey-js (MIT) / mathjs (Apache-2.0) / better-sqlite3 (MIT) / openai (Apache-2.0) / @google/generative-ai (Apache-2.0) / dotenv (BSD-2-Clause)。いずれも CC BY-NC のコードと同梱して差し支えない。
- **ミニゲーム**: スロット・ポーカー・麻雀・ヨット・ヒット＆ブロウはルールの実装であり著作物の複製ではない。親密度ポイントは換金・移転できず賭博性なし。`hitblow-words.ts` の英単語は一般語のみ。
- **AI 生成であることの表示**: `isBot: true` とプロフィールの説明で、人間の発言と誤認させない要件（OpenAI 利用規約）を満たす。
- **シークレット**: `.env` と `dist/` は git 管轄外。`_session-archives` の実ハンドルは Bot 自身と例示用のみ。`_ideas/.research/` は git 管轄外。
