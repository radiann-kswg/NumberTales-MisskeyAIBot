## 変更内容

### client.ts — `fetchEmojis()` に差し替え

`fetchEmojiNames()` を廃止して `fetchEmojis(): Promise<EmojiInfo[]>` に置き換えた。各絵文字の `name / aliases / category / tags` を全部持って返す形になっている。

### weekly-poll.ts — フォールバック解決ロジック

`resolveCoreFolderEmoji(num, emojis)` を追加。解決の優先順はこの通りだよ。

| 優先度 | 判定内容                                                                             |
| ------ | ------------------------------------------------------------------------------------ |
| 1      | `aphrnts{Num}_corefolder` が `name` または `aliases` に完全一致する                  |
| 2      | `aphrnts{Num}` プレフィックスを持ち、`category` または `tags` に `corefolder` を含む |
| 3      | `aphrnts{Num}` プレフィックスを持つ絵文字の先頭1件                                   |
| 4      | 解決不能 → `null`（候補除外のトリガー）                                              |

`hasCoreFolderEmoji()` も内部で `resolveCoreFolderEmoji()` を使う形に変えたので、候補選出フィルターと選択肢ラベル生成の両方が同じロジックを参照している。絵文字キャッシュ未取得時はチェックをスキップして標準名でフォールバックするダウン耐性もそのまま残してあるよ。
