### 3. `√N` バグ修正（`a15642f`）

**現象**: `√10` を含む計算式で mathjs がエラーを返す。

**原因**: `.replace(/√/g, 'sqrt')` が `√10` → `sqrt10`（括弧なし）に変換してしまい、
mathjs が `sqrt10` を未定義変数として解釈した。

**修正**: `src/features/f06/index.ts` の正規化処理を改善。

```typescript
// BEFORE（括弧なし → エラー）
.replace(/√/g, 'sqrt')

// AFTER（括弧付きに変換）
.replace(/√\s*([0-9.]+)/g, 'sqrt($1)')   // √10 → sqrt(10)
.replace(/√\s*\(/g, 'sqrt(')              // √(N+1) → sqrt(N+1)
.replace(/√/g, 'sqrt')                    // その他の残り
```

**本番確認**: `(1+√5)/2` → `1.618033989`（黄金比）✓

- nDm 記法: `/(\d*)([dD])(\d+)/` でマッチ

- 上限: ダイス数 100 以下・面数 10000 以下
- B ランク Precision 演出（3 テンプレートからランダム）:
  - 「ちょっと待ってね……D20 でロール！→ 13 だよ」
  - 「えーっと…2D6 の出目は…… [3, 5] = 8 だよ」
  - 「精度は保証するよ。D6 → 4 が出たよ」

## 技術的知見・注意事項

### PowerShell での Unicode 文字扱い

PowerShell の here-string (`@" ... "@`) は `√` 等の Unicode 文字を破壊する場合がある。
デバッグスクリプトは `.cache/` にファイルとして保存し、`node` で直接実行すること。

```powershell
# ❌ Here-string は√を壊すことがある
node --input-type=module @" ... "@

# ✅ ファイルに保存してから実行
node .cache/debug-f06.mjs
```

### mathjs の `sqrt` 記法

`math.evaluate()` は `sqrt10`（括弧なし）を変数名として解釈する。
`√` → `sqrt(N)` 変換時は必ず括弧を補完すること。
