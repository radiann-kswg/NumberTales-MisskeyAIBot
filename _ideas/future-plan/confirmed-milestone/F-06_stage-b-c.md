## Stage C — 画数・宿曜（高難度）

### C-1: 姓名判断（五格）

**課題（実装前に解決が必要）:**

1. **漢字画数辞書が必要**
   Unicode の CJK 統合漢字（U+4E00〜U+9FFF）全域をカバーする画数テーブルが必要。
   既存の OSS 辞書（例: `kanji-to-kakusuu` 等）を検討するか、自前で持つか要検討。
   常用漢字 2136 字のみに絞ることで辞書を小さくする選択肢もある。

2. **字体の扱い（旧字体 vs 新字体）**
   姓名判断では旧字体（例: 「邊」vs「辺」）での画数が重視される流派もある。
   どちらに統一するか方針を決める必要がある。

3. **五格の定義**

   | 格   | 計算対象                      |
   | ---- | ----------------------------- |
   | 天格 | 姓の総画数                    |
   | 地格 | 名の総画数                    |
   | 人格 | 姓の最後の1字 + 名の最初の1字 |
   | 外格 | 天格 + 地格 - 人格            |
   | 総格 | 天格 + 地格（全文字）         |

### C-2: 宿曜（二十八宿）

**計算概要:**

- 生年月日 → ユリウス通日 → 28 で割った余り → 宿名

**課題:**

- 宿名 28 種と意味の定数テーブルが必要
- 暦法変換（グレゴリオ暦 → ユリウス通日）の実装が必要

## 方針決定（2026-07-20 追記）: 枡本つづり式・現代数秘の採用

> 参照: [数秘術の計算方法・調べ方（マンガ数秘らぼ / 枡本つづり）](https://tsuduri-illust.com/numerotekeisan)

user の提案により、Stage B の計算方式は上記サイトの現代数秘方式をベースに実装する。

### ブロッカー解消

従来の課題「ひらがな→数値マッピングの方式選定（五十音カバラの流派問題）」は、
本方式では**発生しない**。名前を**ヘボン式ローマ字へ変換してからピタゴラス式で数値化**する
フローのため、五十音カバラのマッピング表そのものが不要になる。

### 計算フロー

1. フルネーム（かな）→ ヘボン式ローマ字変換
   - 長音「お」: 末尾のみ `O` を表記（みそのお→MISONOO / おおの→ONO）
   - 長音「う」: 常に `U` を入れない（さとう→SATO / ゆうか→YUKA）
   - 漢字が切り替わる箇所は長音扱いしない（まつうら→MATSUURA）
   - 「ー」は省略（ただし「イ」「ィ」は表記）／「っ」は子音重ね（CH の前は T）
   - 「ん」= N（ただし B・M・P の前は M）／ふ=FU・つ=TSU・ず/づ=ZU
2. ローマ字各文字 → ピタゴラス式数値（A=1..I=9, J=1.. の標準対応表）
3. ナンバー算出:
   - **D（ディスティニー）**: 全文字の合計を縮約
   - **S（ソウル）**: 母音（a/i/u/e/o）のみ合計
   - **P（パーソナリティ）**: 子音のみ合計（D−S でも可）
   - **IT（インテンシティ）**: 変換後に最も多く出現する数
   - **LL（ライフレッスン）**: 変換後に出現しない数
   - **M（マチュリティ）**: LP + D（ゾロ目はそのまま加算）
   - **B（バースデー）**: 誕生「日」のみ縮約（11日・22日はそのまま）※生年月日系の追加分
   - 11・22・33 のゾロ目は縮約ストップ（LP と同じ規則）

### 実装メモ

- かな→ヘボン式変換器（上記例外規則込み）が本体。`features/f06/` に `hepburn.ts` として実装し、
  単体テストで上記の例（御園生/大野/佐藤/松浦/ほっち/なんば等）を網羅する。
- ユーザー入力はかな・ローマ字どちらも受付（ローマ字直接入力ならヘボン変換をスキップ）。
- **名前はユーザー個人情報のため永続保存しない**（既存方針に従い、計算のみ行い破棄）。
- 解釈文（各ナンバーの意味テキスト）は**サイトからの転載はせず**、user 監修のオリジナル文を
  プールデータとして用意する。計算方式の参照元としてサイトへのクレジットをドキュメントに記載する。
- 実装優先順位の見直し: B-1/B-2 のブロッカーが消えたため、**Stage B（D/S/P/IT/LL/M/B）を
  月命星（B-3）より先に着手してもよい**。
