## 概要

毎日1回、ユーザーがメンションすることで「今日のエンジェルナンバー」をランダムに引いてくれる占い機能。
F-06の数字・ヌメロジー世界観を「毎日の習慣」として定着させるための機能。

藍(Ai)の「占い」機能との差別化:
- 単なる吉凶ではなく **エンジェルナンバーの意味とメッセージ** で個性を出す
- **担当キャラクターの専門性・口調** で解釈する（前提A実装済みの機能を活用）
- F-06の知識ベース（B-4 エンジェルナンバーデータ）を共有して一貫した世界観を維持

## コマンドトリガー

```
「おみくじ」「今日の数字は？」「エンジェルナンバーを引いて」「数字を引いて」
「今日の運勢」「今日のナンバーは？」「今日の数字占いしてほしい」
```

意図分類: `angel-number-fortune`（`classifyIntent()` に追加）

---

## ゲームフロー

```
[1] ユーザーがトリガーワード付きでメンション

[2] セッションDBで「今日は既に引いたか？」をチェック
    → 引いた場合: 「今日のナンバーはもう出たよ！また明日ね」とやわらかく拒否

[3] コード側でランダムにエンジェルナンバーを抽選
    → 数字プールから重み付き抽選（後述）

[4] 抽選結果 + エンジェルナンバーデータ（意味・キーワード）を組み立て

[5] 担当キャラクターのシステムプロンプト + 数字データを LLM に渡して
    キャラクターらしい解釈文を生成

[6] 投稿:
    本文 (100文字以内): キャラの口調で今日のナンバーと一言メッセージ
    CW 内: 数字の詳細な意味・キーワード・アドバイス

[7] セッションDBに today_fortune_date を記録
```

## 数字抽選プール（重み付き）

### プール設計

ランダム性は **コード側で確定的に生成**（LLMに乱数を生成させない）。

## 出力例

### 1桁を引いた場合（担当: 000(チトセ)、数字: 3）

```
本文（公開）:
今日は「3」のエンジェルナンバーが出たよ。表現と創造のエネルギーが溢れる日だ。
作りたいもの、伝えたいこと、素直に動かしてみて。

CW（詳細）:
【エンジェルナンバー 3】
メッセージ: 願いは叶います
キーワード: 表現・創造・拡張・喜び
天使のサポートを受けながら、内なる光を世界へ表現するとき。
アイデアを形にする力が高まっている一日です。
```

### 3桁ゾロ目を引いた場合（担当: 74(ナナヨ)、数字: 777）

```
本文（公開）:
……777。天が選んだ数字を伝える。精神の目覚めと深い知恵の流れが、今日のあなたに宿っている。

CW（詳細）:
【エンジェルナンバー 777】
メッセージ: 精神の目覚めと豊かな知恵
キーワード: ラッキーナンバー・精神性・探求・直観
正しい道を歩んでいることを天が肯定している。
内なる声を信じ、直観に従うことで新たな扉が開く。
```

## LTL汚染対策

- **返信の公開範囲**: `followers` 指定（フォロワー限定）または通常のリプライ
- **1日1回制限**: 日付単位でリセット（JST: UTC+9）
- **連続リクエスト抑止**: 制限時のメッセージはキャラらしく、ルール提示ではなくキャラとして自然に断る
