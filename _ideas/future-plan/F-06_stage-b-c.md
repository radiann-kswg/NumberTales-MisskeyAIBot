## Stage B — 名前文字列ヌメロジー

### B-1: デスティニーナンバー（表現数）

**流派:** ピタゴラス式 / カルデア式（両対応）

**計算方法:**

- フルネームの各文字に数値を割り当てて合計し、縮約（マスターナンバーで停止）

**課題（未決定事項）:**

- **ひらがな → 数値マッピングの方式選定が必要**
  代表的な「五十音カバラ」方式が複数存在し、流派によって異なる。
  実装前にどのマッピングを採用するか確定させること。

  | 方式               | あ      | い  | う  | え  | お  | 参考               |
  | ------------------ | ------- | --- | --- | --- | --- | ------------------ |
  | 片山式（現代数秘） | 1       | 1   | 3   | 5   | 6   | よく使われる       |
  | 並木式             | 1       | 2   | 3   | 4   | 5   | 母音 1-5 固定      |
  | ピタゴラス直訳     | A=1相当 | …   | …   | …   | …   | アルファベット起源 |

- アルファベット名への対応は確立されているため、英名対応は先に実装可能。

### B-2: ソウルナンバー（魂の衝動数）

**流派:** ピタゴラス式

**計算方法:**

- フルネームのひらがな表記から「あいうえお」のみを抜き出して縮約

**課題:**

- 「母音」の定義が日本語では曖昧（`ゃゅょ` 等の拗音をどう扱うか）
- B-1 と同じひらがなマッピング問題が先行して解決している必要がある

## Stage C — 画数・宿曜（高難度）

### C-1: 姓名判断（五格）

**課題（実装前に解決が必要）:**

1. **漢字画数辞書が必要**
   Unicode の CJK 統合漢字（U+4E00〜U+9FFF）全域をカバーする画数テーブルが必要。
   既存の OSS 辞書（例: `kanji-to-kakusuu` 等）を検討するか、自前で持つか要検討。
   常用漢字 2136 字のみに絞ることで辞書を小さくする選択肢もある。

2. **字体の扱い（旧字体 vs 新字体）**
   姓名判断では旧字体（例: 「邊」vs「辺」）での画数が重視される流派もある。
   どちらに統一するか方針を決める必要がある。

3. **五格の定義**

   | 格   | 計算対象                      |
   | ---- | ----------------------------- |
   | 天格 | 姓の総画数                    |
   | 地格 | 名の総画数                    |
   | 人格 | 姓の最後の1字 + 名の最初の1字 |
   | 外格 | 天格 + 地格 - 人格            |
   | 総格 | 天格 + 地格（全文字）         |

### C-2: 宿曜（二十八宿）

**計算概要:**

- 生年月日 → ユリウス通日 → 28 で割った余り → 宿名

**課題:**

- 宿名 28 種と意味の定数テーブルが必要
- 暦法変換（グレゴリオ暦 → ユリウス通日）の実装が必要
