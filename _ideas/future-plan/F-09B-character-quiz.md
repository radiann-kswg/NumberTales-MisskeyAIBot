# F-09B: ナンバーテールズ キャラクタークイズ

> 作成日: 2026-06-22  
> ステータス: **構想段階**（監修フロー確立後に実装）  
> 関連: [creations-db-reference-expansion](./creations-db-reference-expansion.md)

---

## 概要

創作DB (`_creations-db`) のキャラクターデータを活用して、
ナンバーテールズのキャラクターに関するクイズをBot上で提供する機能。

フォロワーがナンバーテールズのキャラクターを自然に覚えていく導線になる。

---

## コマンドトリガー

```
「クイズを出して」「ナンバーテールズクイズ」「キャラクタークイズ」
「〇〇についてクイズしよう」「テストしてほしい」
```

意図分類: `quiz-start` / `quiz-answer`（ゲーム中の回答）

---

## クイズ種別（案）

### タイプ A: 「この番号は誰でしょう？」

Bot がキャラクターの特徴ヒントを提示 → ユーザーが名前 or 番号を答える。

```
例:
Bot: 「タロットカードが得意で、恋愛と謎めいた雰囲気を持つナンバーテールズは誰でしょう？
      ① 78(ナナハ)  ② 47(シナ)  ③ 74(ナナヨ)  ④ 28(ニハチ)」

正解: ① 78(ナナハ)
```

**ヒントの情報源**: `Hobby` / `Character` / `SpecialSkill` / `Favor` フィールド（創作DB）

### タイプ B: 「このキャラクターの得意なことは？」

Bot がキャラクター名 or 番号を提示 → 専門性・趣味を4択で答える。

```
例:
Bot: 「28(ニハチ)の得意なことはどれでしょう？
      ① タロット占い  ② 数学  ③ 護身術  ④ 天のお告げ」

正解: ② 数学
```

### タイプ C: 「このヌメロジースペックは誰のもの？」

`NumerospecAbout` フィールドを活用。数秘的な役割からキャラを当てる。

```
例:
Bot: 「"ありのままに行動する" という数秘スペックを持つのは何番でしょう？」

正解: 1番（該当キャラ）
```

> ⚠️ `NumerospecAbout` が非公開（`hideText` 付き）のキャラは除外する。

---

## クイズ生成フロー

```
[1] ユーザーがクイズ起動コマンドを送信

[2] 創作DBからクイズ出題可能なキャラクター一覧を取得
    → 公開済み & 公開フィールドがあるものに限定

[3] ランダムにキャラクターとクイズタイプを選択

[4] 正解と不正解の選択肢（3件）を自動生成
    → 不正解はDBから別キャラのデータを使う
    → 選択肢の順序はランダム化

[5] 問題文を担当キャラクターの口調で LLM 生成

[6] セッションDBに「正解番号」と「出題したキャラID」を保存

[7] ユーザーの返答を受け取り、正誤判定
    → 担当キャラクターの口調で結果フィードバック
```

---

## 監修フロー（実装必須前提）

クイズは公式設定に基づく必要があるため、**クライアント（user）の監修が前提**。

### 監修が必要な理由

- 誤った設定を「正解」として提示するリスクを避ける
- 未公開情報の混入防止（`hideText` が入っているフィールドの扱い）
- キャラクターの公式イメージと合わない選択肢生成を防ぐ

### 推奨フロー

```
[Phase 1] クイズデータ静的ファイル作成
  → クライアントが承認済みの Q&Aセットを JSON で用意
  → Bot はそのファイルから出題するだけ（動的生成しない）

[Phase 2] 半自動生成 + 監修
  → DBから自動生成した候補問題をクライアントが確認
  → 承認されたものだけをPool Fileに追加

[Phase 3] 動的生成（将来）
  → 公開フィールド限定・LLMが出題 → 自動フィルタリング
```

**当面は Phase 1（静的ファイル）での実装を推奨。**

## クイズデータフォーマット案

```json
// src/features/f09b/quiz-data.json
[
  {
    "id": "q001",
    "type": "A",
    "hint": "タロットカードを得意とし、謎めいた雰囲気を持つナンバーテールズは？",
    "choices": [
      { "label": "78(ナナハ)", "correct": true },
      { "label": "47(シナ)", "correct": false },
      { "label": "74(ナナヨ)", "correct": false },
      { "label": "28(ニハチ)", "correct": false }
    ],
    "correct_commentary": "正解！78(ナナハ)はタロット占いを得意としているよ。",
    "wrong_commentary": "惜しい！答えは78(ナナハ)。タロットカードが大好きなんだよ。"
  }
]
```

## セッションDB拡張

```sql
CREATE TABLE IF NOT EXISTS quiz_sessions (
  user_id       TEXT PRIMARY KEY,
  question_id   TEXT NOT NULL,     -- quiz-data.json の問題ID
  correct_index INTEGER NOT NULL,  -- 正解の選択肢インデックス
  created_at    INTEGER NOT NULL   -- セッション TTL: 10分
);
```

## 担当キャラクター別の演出

- **000(チトセ)**: 「じゃあクイズだ。エンジニア的に分析して考えてみて。」
- **78(ナナハ)**: 「タロットの導きで問題を選んだよ。答えてみて。」
- **47(シナ)**: 「……あなたがどれだけ知っているか、見せてもらおうか。」
- **74(ナナヨ)**: 「天の声が問いを授けた。答えてごらん。」
