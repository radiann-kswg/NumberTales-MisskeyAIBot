## Stage B: 計算仕様（枡本つづり式）

### ヘボン式ローマ字変換（実装の本体）

`src/features/f06/hepburn.ts`（新規）にかな→ヘボン式変換器を実装する。例外規則:

- 長音「お」: 末尾のみ `O` 表記（みそのお→MISONOO / おおの→ONO / こおり→KORI）
- 長音「う」: 常に `U` を入れない（さとう→SATO / ゆうか→YUKA / こうち→KOCHI）
- 漢字が切り替わる箇所は長音扱いしない（まつうら→MATSUURA / ひろおか→HIROOKA）
- 「ー」は省略（ニーナ→NINA）。ただし「イ」「ィ」は表記（ニイナ→NIINA）
- 「っ」は子音重ね。ただし CH の前は T（ほっち→HOTCHI）
- 「ん」= N。ただし B・M・P の前は M（なんば→NAMBA）
- ふ=FU / つ=TSU / ず・づ=ZU

**単体テスト**: 上記の実例（御園生・大野・佐藤・松浦・ほっち・なんば等）を全ケース網羅すること。

### 数値化とナンバー算出

ローマ字各文字をピタゴラス式対応表（A=1..I=9, J=1.. の標準表）で数値化し:

| ナンバー | 算出 |
| -------- | ---- |
| D（ディスティニー） | 全文字合計を縮約 |
| S（ソウル） | 母音（A/I/U/E/O）のみ合計を縮約 |
| P（パーソナリティ） | 子音のみ合計を縮約（D−S でも可） |
| IT（インテンシティ） | 最多出現数 |
| LL（ライフレッスン） | 未出現数 |
| M（マチュリティ） | LP + D（ゾロ目はそのまま加算して縮約） |
| B（バースデー） | 誕生「日」のみ縮約（11日・22日はそのまま） |

- 11・22・33 のゾロ目は縮約ストップ（Stage A の LP と同一規則・既存実装を流用）
- ユーザー入力はかな・ローマ字どちらも受付（ローマ字直接入力はヘボン変換スキップ）

### 制約（重要）

- **名前は個人情報のため永続保存しない**（計算のみ行い破棄。既存方針に従う）
- 解釈文はサイトから転載せず、**user 監修のオリジナル文**をプールデータとして用意
- 計算方式の参照元クレジットをドキュメント（本ファイル＋README 機能説明）に記載
