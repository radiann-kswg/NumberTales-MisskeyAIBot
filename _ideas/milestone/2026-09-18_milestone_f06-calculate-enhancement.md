## 概要

F-06 の数式計算（`calculate`）を、**表示（清書）**と**計算能力（評価）**の両面で強化する。
グリルで分かった前提が 2 つある。

- mathjs の結果は、行列も含めて常に 1 行で出てくる。画像が活きるのは結果そのものではなく、**縦構造を持つ式の清書**
- これまで「計算できない」とされていたものの多くは、評価ではなく**抽出の失敗**だった。単位換算も物理定数も、mathjs は標準で扱える

## 決定事項

### 清書

| 項目 | 決定 |
| --- | --- |
| 自然な表記への変換 | mathjs の書き方を自然な数式に直す関数を 1 本だけ作る（`*`→`×`、`sqrt(…)`→`√`、整数の指数→上付き、`1.2e+21`→`1.2×10²¹`）。`/` は `÷` にしない（分数として読まれるため）。**この出力をそのままプレーン式にし**、PM 絵文字はそれを 1 字ずつ置き換えて作る |
| プレーン式 | 自然な表記で書き、そのまま `/calc` に貼り直せるようにする（抽出側の正規化は `ebcbd60` で対応済み）。清書した式には必ず併記する |
| PM 絵文字の対応表 | `calculate` が出力する字をすべて入れる。既存の数字と `+ - × ÷ = ? ( )` に、`.` `/` `^` `√` `*` `,` `%` `[` `]`、英字 a–z / A–Z、上付きを足す。表に無い字は生の文字のまま出す。基本コード 456 個が 5 色すべてに欠けなく揃っていることは確認済み（2026-09-18） |
| 色 | 墨（接尾辞 `p`）で固定する |
| 清書の手段の順序 | ① **PM 絵文字**（本文に収まるとき）→ ② **画像**（縦構造がある、または ① が収まらないとき。ただし結果の長さが上限値以下のときだけ）→ ③ **プレーン式だけ**（画像が使えない・失敗した・大きすぎるとき）→ ④ **プレーン式を先頭だけ残して切り詰める**（プレーン式だけでも本文の上限を超えるとき。「長すぎるから先頭だけ載せるね」と添える） |
| 画像にする条件（縦構造） | `toTex()` の出力に分数（`\frac`。**1 段でも画像にする**ので `100/4 = 25` も対象）、入れ子の根号、行列が含まれるとき |
| 画像の上限値 | まずは結果 400 字前後（10×10 の行列が収まる程度）から始める。読みやすさは実物を見ないと決められないので、**定数にして実物を見ながら調整する** |
| 本文の上限 | インスタンスの `maxNoteTextLength` は 3000（2026-09-18 実測）。F-06 の投稿口は長さを確かめずに送るので、上限を超えると無返答になる。ガードは `calculate` の中に置く（F-06 で結果の長さが青天井なのは `calculate` だけ） |

### 評価

| 項目 | 決定 |
| --- | --- |
| 道具 | mathjs で届く範囲を先に取る。Wolfram（F-17D）は後回し |
| 単位換算 | `/calc 5 km to mile` は `ccc6045` 以降すでに動く。`createUnit` で光年などの語彙を足す。**自然文での単位換算は段階的に対応する**（日本語の単位名の対訳表と、構文の抽出が要るため） |
| 微分 | 自然文で受ける（「微分して」）。微分する変数は、式に `x` があれば `x`、無くて英字が 1 種類だけならその字にする |
| 厳密値 | 既定は小数のまま。割り算を含み、**小数が終わらない**答え（分母に 2 と 5 以外の素因数が残るもの）にだけ分数を併記する。`1/3` には添え、`1/4 = 0.25` には添えない |
