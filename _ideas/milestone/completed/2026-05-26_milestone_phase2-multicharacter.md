# Phase 2 マルチキャラクター基盤 — 切り替え・永続化・本番確認

> 作成日: 2026-05-26
> ステータス: **完了** ✅

---

## 概要

Phase 2 のマルチキャラクター対応として、公開済みナンバーテールズ個体への切り替え基盤を実装した。
あわせて、ユーザー別担当の保持、管理者による標準担当変更、担当解除、切り替えヘルプ、本番反映まで完了した。

---

## 完了項目

### 1. 動的キャラクタープロンプト生成 ✅

- `_creations-db/data/Works_NumberTales/DataBases/db_Primary.json` から `Progress = released` の個体を読み込み
- `ConversationPattern` がある個体は会話スタイルを優先使用
- `ConversationPattern` がない個体は `Character` / `Summary` / `Relation` / 呼称系フィールドから簡易プロンプトを生成

### 2. ユーザー別キャラクター切り替え ✅

- 番号指定: `1番機と話したい` / `#3にお願い` / `3番機に来て`
- 名前指定: `ハジメちゃんと話したい` / `ナオで頼む`
- キャラクター切り替えとフォーム切り替えを同時指定可能
  - 例: `ハジメちゃんをコアフォルダにして`

### 3. 状態管理と永続化 ✅

- ユーザーごとの個別担当キャラクターを SQLite に保存
- 全体デフォルト担当を SQLite に保存
- Bot 再起動後も状態を復元
- キャラクター切り替え・解除時は会話履歴をクリアして文脈混線を防止

### 4. 管理者コマンドと解除導線 ✅

- `ADMIN_USER_IDS` に含まれるユーザーのみ全体デフォルト担当を変更可能
- 例: `全体のデフォルトを3番機にして`
- 個別担当解除コマンドを追加
  - 例: `担当を標準に戻して` / `キャラクター設定を解除して`
- 切り替えヘルプ応答を追加
