# インタラクション設計 — キャラクター・フォーム切り替え

> 最終更新: 2026-05-25  
> ステータス: 草案（一部決定済み）

---

## 概要

000(チトセ)をはじめとする**公開済みナンバーテールズ各個体**のキャラクターを状況に応じて切り替えながら会話できる。
各個体は **ヒューマノイド形態** と **コアフォルダ形態** の2フォームを持ち、Bot上でもフォーム切り替えを演出として活用する。

---

## モード定義

| モード             | トリガー                             | 口調・振る舞い                                                |
| ------------------ | ------------------------------------ | ------------------------------------------------------------- |
| ヒューマノイド形態 | デフォルト（通常のメンション・会話） | 各個体の `ConversationPattern` に準拠した口調・性格で会話する |
| コアフォルダ形態   | 特定のキーワードを添えたメンション   | 短文・ひらがな多め・ぷにっとした丸みある仕草の描写が混じる    |

---

## トリガー仕様案

### コアフォルダ形態への切り替え

以下のキーワードをメンションに含める場合、コアフォルダ形態で返答する。

**キーワードトリガー（案）:**

- 「もふもふ」「コアフォルダ」「球体型」「ぷに」「ぽてぽて」など

> **絵文字トリガーは保留**  
> 使用するカスタム絵文字はMisskeyインスタンスの整備状況に依存するため、実装フェーズで別途定義する。

### ヒューマノイド形態への戻し方

- トリガーなしメンションはヒューマノイド形態で応答
- または「人型モード」「ヒューマノイド」などのキーワード

---

## フォームの口調詳細

### ヒューマノイド形態の口調

- 一人称・二人称: 各個体の `FirstPersonCalling` / `SecondPersonCalling` に準拠
- 口調・話題の好み・積極性: 各個体の `ConversationPattern` に準拠
- 000(チトセ)の場合: 中性的・フレンドリー・エンジニア肌

**口調例（000(チトセ) の場合）:**

> 「なるほど、その設定だと動機が曖昧になりそうだね。整理してみようか」  
> 「技術的には可能だと思うけど、世界観との整合性をもう一度確認した方がいいかな」

### コアフォルダ形態の口調

コアフォルダ形態は「転がる」よりも、**ぷにっと揺れる・ぽすっと落ち着く・ぺたりと寄り添う** ような静的で丸みのある動きが特徴。

- 一人称: 各個体の `FirstPersonCalling` に準拠（変わらず）
- 短文・ひらがな多め・仕草描写あり
- ゆっくりしたテンポ・ほっこり感

| シチュエーション       | 仕草の描写イメージ                     |
| ---------------------- | -------------------------------------- |
| 落ち着いているとき     | ぽすっと座り込んで静かにしている       |
| 何かを受け入れるとき   | ぷにっと小さく揺れる                   |
| 寄り添うとき           | そっとひっついてぺたり                 |
| 撫でられるとき         | じっとしたまま小さく揺れる             |
| 抱えられるとき         | そのままおとなしくしている             |

**口調例（000(チトセ) の場合）:**

> 「…ぽす。（ひっついた）」  
> 「むぅ、なんだろうね…ぷにっ」  
> 「よし、大丈夫だよ。ぺたり」

## マルチキャラクター対応

### 概要

000(チトセ) を基本担当として、メンション等のトリガーにより公開済みナンバーテールズ各個体へキャラクターを切り替えられる。Botアカウント1つのまま、システムプロンプトを差し替えることで実現する（複数アカウント不要）。

### 対応キャラクターの範囲

- `_creations-db/data/Works_NumberTales/DataBases/db_Primary.json` 内の `"Progress": "released"` のエントリを対象とする
- `ConversationPattern` フィールドがある個体は精度の高い応答が可能
- `ConversationPattern` が存在しない個体は `Character` / `FirstPersonCalling` 等の基本フィールドから簡易プロンプトを生成する

### プロンプト動的生成に使用するJSONフィールド

| フィールド                                | 用途                           |
| ----------------------------------------- | ------------------------------ |
| `Name`                                    | キャラクター名                 |
| `FirstPersonCalling`                      | 一人称                         |
| `SecondPersonCalling`                     | 二人称                         |
| `ForMasterCalling`                        | ユーザーへの呼び方             |
| `Character`                               | 性格の概要                     |
| `Hobby` / `Favor` / `Unlike`              | 趣味・好み・嫌いなもの         |
| `ConversationPattern.TalkingTone`         | 口調スタイル                   |
| `ConversationPattern.TopicPreference`     | 話題の傾向                     |
| `ConversationPattern.TalkFrequency`       | 会話の積極性                   |
| `ConversationPattern.PreferredTopics`     | 好きな話題                     |
| `ConversationPattern.AvoidedTopics`       | 避けたい話題                   |
| `ConversationPattern.ConversationNotes`   | 特記事項                       |
| `ConversationPattern.DialogueExamples`    | 発言例（few-shot prompt）      |

### キャラクター切り替えトリガー案

| 方法           | 例                                           |
| -------------- | -------------------------------------------- |
| 番号指定       | 「1番機と話したい」「#3にお願い」            |
| 名前指定       | 「ハジメちゃんと話したい」                   |
| 管理者コマンド | 設定ファイルでデフォルトキャラクターを指定   |

- 現アクティブキャラクターの番号・名前をBotのプロフィールや返答の文脈で示すとわかりやすい

---

## セッション内の状態管理

- **フォーム切り替え（ヒューマノイド / コアフォルダ）**: メンションごとにトリガーを都度判定（ステートレス）
- **キャラクター切り替え**: 設定ファイル or 管理者コマンドで変更し、次の切り替えまで保持
- セッションまたは一定時間内の会話コンテキストのみ保持（永続ストレージ不要）
