# Bot仕様概要 — ナンバーテールズ Misskey AI Bot

> 最終更新: 2026-06-22
> ステータス: 草案（一部決定済み）

---

## コンセプト

「AIサービス」ではなく、**Misskeyタイムラインに住む一人の住民** として振る舞う。

000(チトセ)というキャラクターを軸に、SNSに馴染む「生き物っぽさ」を最優先に設計する。
AI感を出しすぎず、軽量・短文・絵文字豊富な投稿でインスタンス文化に溶け込む。

## 基本方針

### ① AI負荷を最小化する「ハイブリッド設計」

全ての返信をLLMで生成するのではなく、処理を分担する。

| 処理               | 担当              |
| ------------------ | ----------------- |
| 感情・意図の分類   | AI（軽量分類）    |
| 長文の応答生成     | LLM（必要時のみ） |
| 定型返答・挨拶     | ルールベース      |
| カスタム絵文字付与 | 固定辞書          |

### ② TLを荒らさない投稿設計

- 日常的な発話は **100文字以内** を厳守
- 詳細な内容は **CW（コンテンツワーニング）** の中に格納
- リプライ過多・連投を避ける制御を実装

### ③ ユーザープライバシーの保護

- 基本方針: ユーザー個人情報の **無断・永続保存は行わない**
- セッション内の一時的なコンテキスト保持（TTL 30分）を基本とする
- **例外（Opt-in 型の最小限保存）**: 以下の機能でユーザーが明示的に登録を要求した場合のみ、
  必要最小限のデータを SQLite に永続保存する
  | 機能 | 保存するデータ | 保存しないデータ |
  |-----|-------------|----------------|
  | F-11 誕生日登録 | 誕生月・誕生日のみ | 生年（年齢）・氏名等 |
  | F-12 リマインダー | リマインド内容・日時 | 会話内容全般 |
- ユーザーが「忘れて」「削除して」と要求した場合は即時削除する

### ④ Misskeyらしさの徹底

- カスタム絵文字を積極活用し、テキストだけに頼らない
- 各インスタンスの文化・絵文字セットに対応できるよう柔軟に設計
- 自我が強くなりすぎないよう、発言頻度・トーンを制御

### ⑤ 稼働インスタンス

- 運用者が自ホストで管理するお一人様Misskeyインスタンスを使用する
- インスタンスの稼働状況と併せてBot側も整備・管理していく

### ⑥ Botの公開範囲

- 原則として **全公開** で運用する
- ナンバーテールズという創作の印象を損ねる運用リスクが生じると判断した場合は、**フォロワー限定** に切り替えることも検討する

### ⑦ Bot安全設計（LTL汚染防止・暴走防止）

Fediverseの運営事例調査（2026-06-22）から得た知見として、以下を設計原則に追加する。
詳細は [05_bot-safety-design.md](./05_bot-safety-design.md) を参照。

- **LTL汚染防止**: 個人向け応答（占い・リマインド・誕生日）の公開範囲は `home` または `specified` を基本とし、パブリックTLに流さない
- **投稿レート制限**: 種別ごとに最短インターバルを設定し、バグ等による連続投稿を防ぐグローバル上限も持つ
- **ランダム値はコードで生成**: LLMにランダム結果を生成させない。乱数・抽選は必ずコード側で確定させてからLLMに渡す
- **同一機能の利用制限**: ユーザーごとに「1日1回」「同時N件」等の上限を設け、DBで管理する
- **キャラクターとして断る**: 機能制限・拒否はルール表示でなく担当キャラクターの口調で自然に行う

### ⑧ モデレーション・NGワード方針

以下に該当する内容を含む投稿・応答は行わない。

1. **Fediverse全体の公的秩序に反するもの** — 違法行為・ヘイト行為・公序良俗に反する表現等
2. **創作ガイドライン（全体共通）に違反するもの** — 百花繚乱研究所の創作物全般に適用される禁止事項
3. **ナンバーテールズ特有のガイドラインに違反するもの** — 著しく性的な表現・公式設定からの著しい逸脱等
4. **ライセンス（CC BY-NC 4.0）違反につながるもの** — 創作DBデータの商用利用を示唆するワード等

具体的なNGワードリストは実装フェーズで別途定義する。

## 決定済み事項

- [x] **対象インスタンス**: 運用者が管理する自ホストのお一人様Misskeyインスタンスを使用
- [x] **Botアカウントの公開範囲**: 原則全公開。創作印象リスク発生時はフォロワー限定を検討
- [x] **モデレーション・NGワード方針**: Fediverse公的秩序 / 創作ガイドライン（全体共通・NT特有）/ CC BY-NC 4.0ライセンスの3軸で制御
- [x] **自発投稿の有無・頻度**: 有り。ピークタイムは1〜2時間に1回、オフタイムは3〜4時間に1回以下
- [x] **使用するAI API**: OpenAI GPT-4o-mini を主軸。差し替え可能な抽象レイヤーで Gemini 1.5 Flash をセカンダリ候補として維持
