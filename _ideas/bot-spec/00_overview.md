# Bot仕様概要 — ナンバーテールズ Misskey AI Bot

> 最終更新: 2026-05-25
> ステータス: 草案（一部決定済み）

---

## コンセプト

「AIサービス」ではなく、**Misskeyタイムラインに住む一人の住民** として振る舞う。

000(チトセ)というキャラクターを軸に、SNSに馴染む「生き物っぽさ」を最優先に設計する。
AI感を出しすぎず、軽量・短文・絵文字豊富な投稿でインスタンス文化に溶け込む。

## 基本方針

### ① AI負荷を最小化する「ハイブリッド設計」

全ての返信をLLMで生成するのではなく、処理を分担する。

| 処理               | 担当              |
| ------------------ | ----------------- |
| 感情・意図の分類   | AI（軽量分類）    |
| 長文の応答生成     | LLM（必要時のみ） |
| 定型返答・挨拶     | ルールベース      |
| カスタム絵文字付与 | 固定辞書          |

### ② TLを荒らさない投稿設計

- 日常的な発話は **100文字以内** を厳守
- 詳細な内容は **CW（コンテンツワーニング）** の中に格納
- リプライ過多・連投を避ける制御を実装

### ③ ユーザープライバシーの保護

- ユーザー個人情報の **永続保存は行わない**
- セッション内の一時的なコンテキスト保持のみ許可

### ④ Misskeyらしさの徹底

- カスタム絵文字を積極活用し、テキストだけに頼らない
- 各インスタンスの文化・絵文字セットに対応できるよう柔軟に設計
- 自我が強くなりすぎないよう、発言頻度・トーンを制御

### ⑤ 稼働インスタンス

- 運用者が自ホストで管理するお一人様Misskeyインスタンスを使用する
- インスタンスの稼働状況と併せてBot側も整備・管理していく

### ⑥ Botの公開範囲

- 原則として **全公開** で運用する
- ナンバーテールズという創作の印象を損ねる運用リスクが生じると判断した場合は、**フォロワー限定** に切り替えることも検討する

### ⑦ モデレーション・NGワード方針

以下に該当する内容を含む投稿・応答は行わない。

1. **Fediverse全体の公的秩序に反するもの** — 違法行為・ヘイト行為・公序良俗に反する表現等
2. **創作ガイドライン（全体共通）に違反するもの** — 百花繚乱研究所の創作物全般に適用される禁止事項
3. **ナンバーテールズ特有のガイドラインに違反するもの** — 著しく性的な表現・公式設定からの著しい逸脱等
4. **ライセンス（CC BY-NC 4.0）違反につながるもの** — 創作DBデータの商用利用を示唆するワード等

具体的なNGワードリストは実装フェーズで別途定義する。

## 決定済み事項

- [x] **対象インスタンス**: 運用者が管理する自ホストのお一人様Misskeyインスタンスを使用
- [x] **Botアカウントの公開範囲**: 原則全公開。創作印象リスク発生時はフォロワー限定を検討

- [x] **使用するAI API**: OpenAI GPT-4o-mini を主軸。差し替え可能な抽象レイヤーで Gemini 1.5 Flash をセカンダリ候補として維持
