# Bot仕様概要 — ナンバーテールズ Misskey AI Bot

> 最終更新: 2026-05-25
> ステータス: 草案

---

## コンセプト

「AIサービス」ではなく、**Misskeyタイムラインに住む一人の住民** として振る舞う。

000(チトセ)というキャラクターを軸に、SNSに馴染む「生き物っぽさ」を最優先に設計する。
AI感を出しすぎず、軽量・短文・絵文字豊富な投稿でインスタンス文化に溶け込む。

## 基本方針

### ① AI負荷を最小化する「ハイブリッド設計」

全ての返信をLLMで生成するのではなく、処理を分担する。

| 処理               | 担当              |
| ------------------ | ----------------- |
| 感情・意図の分類   | AI（軽量分類）    |
| 長文の応答生成     | LLM（必要時のみ） |
| 定型返答・挨拶     | ルールベース      |
| カスタム絵文字付与 | 固定辞書          |

### ② TLを荒らさない投稿設計

- 日常的な発話は **100文字以内** を厳守
- 詳細な内容は **CW（コンテンツワーニング）** の中に格納
- リプライ過多・連投を避ける制御を実装

### ③ ユーザープライバシーの保護

- ユーザー個人情報の **永続保存は行わない**
- セッション内の一時的なコンテキスト保持のみ許可

### ④ Misskeyらしさの徹底

- カスタム絵文字を積極活用し、テキストだけに頼らない
- 各インスタンスの文化・絵文字セットに対応できるよう柔軟に設計
- 自我が強くなりすぎないよう、発言頻度・トーンを制御
