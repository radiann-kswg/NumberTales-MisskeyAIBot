## 想定技術スタック

| レイヤー       | 候補技術                            | 備考                                             |
| -------------- | ----------------------------------- | ------------------------------------------------ |
| 実行ランタイム | Node.js (TypeScript) / Python       | Misskey APIライブラリの充実度からNode.js推奨     |
| Misskey連携    | Misskey.js / WebSocket直接接続      | メンション監視・投稿はWebSocket購読を使用        |
| AI API         | OpenAI API / Google Gemini API      | 未決定。両対応できる抽象レイヤーを挟むことを推奨 |

| 一時ストレージ | SQLite / メモリキャッシュ           | セッションコンテキストの一時保持のみ             |
| デプロイ先     | 自宅サーバー / VPS / クラウド(未定) | 常時起動が必要なためサーバーレスは不向き         |

## システム構成図（概念）

```
Misskey インスタンス
  │
  │  WebSocket (ストリーミングAPI)
  ▼
[ Bot サーバー ]
  │
  ├─ イベントハンドラ
  │    ├─ メンション受信
  │    ├─ ノート受信（TL観測）
  │    └─ タイマー（定期投稿）
  │
  ├─ 意図分類エンジン（ルールベース）
  │    └─ 挨拶 / 雑談 / 創作相談 / リアクション等
  │
  ├─ 応答生成レイヤー
  │    ├─ 定型返答辞書（ルールベース）
  │    └─ LLM呼び出し（OpenAI / Gemini）
  │         └─ システムプロンプト: 000(チトセ)のキャラクター設定
  │
  ├─ 投稿制御（レートリミッタ・重複防止）
  │
  └─ 一時ストレージ（SQLite）
       └─ セッションコンテキスト（短時間TTL）
```

## Misskey API連携

### 使用するAPIエンドポイント（主要）

| 機能               | エンドポイント                      |
| ------------------ | ----------------------------------- |
| ストリーミング接続 | WebSocket: `wss://{host}/streaming` |
| ノート投稿         | `POST /api/notes/create`            |
| リアクション付与   | `POST /api/notes/reactions/create`  |
| TL取得（初期）     | `POST /api/notes/local-timeline`    |
| フォロイーTL       | `POST /api/notes/timeline`          |

### 購読チャンネル

- `main` チャンネル: メンション・返信の受信
- `localTimeline` チャンネル: TL観測（F-04, F-05で使用）
- `homeTimeline` チャンネル: フォロイーの投稿監視（オプション）

## AI API利用方針

### LLM呼び出しを最小化する設計

コスト・安定性のため、LLMは「本当に必要な場面のみ」呼び出す。

```
呼び出す場合:
  - 雑談の自由応答（ルールベースで対応できない場合）
  - 創作支援（壁打ち・お題生成）
  - 長めのCW折りたたみコンテンツ

呼び出さない場合:
  - 挨拶・定型応答
  - リアクション絵文字の選択
  - TL観測レポートの生成（ルールベースで代替）
```

### システムプロンプト設計

`_roleplay-datas/roleplay-prompt.md` の設定を元に構築する。
LLM呼び出し時は常に以下を含む:

1. 000(チトセ)のキャラクター設定（一人称・二人称・口調）
2. 投稿文字数制限（100文字以内・CW折りたたみ指示）
3. 禁止事項（未公開設定の自動生成禁止・性的表現禁止など）

## 投稿制御・レートリミッタ

### 上限設定案

| 対象                     | 上限                         |
| ------------------------ | ---------------------------- |
| 同一ユーザーへのリプライ | 30分に1回                    |
| 自発投稿（深夜雑談）     | 1〜2時間に1回                |
| TL観測レポート           | 1日1〜2回                    |
| 全体投稿数               | 1時間に10投稿 上限（安全弁） |

### 重複・ループ防止

- 自分のノートへのリアクション・リプライは無視
- メンション処理済みIDをキャッシュして二重返答を防止

---

## セキュリティ方針

- Misskey APIトークンは環境変数で管理（ハードコード禁止）
- LLM APIキーも同様に環境変数で管理
- ユーザー投稿内容のログ保存は行わない（一時コンテキストはTTL付き）
- プロンプトインジェクション対策: ユーザー入力をシステムプロンプトに直接展開しない
