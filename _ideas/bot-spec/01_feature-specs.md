> 最終更新: 2026-05-25
> ステータス: 草案

## F-01: ゆる会話（メンション応答）

### 概要

ユーザーからメンション（`@000chitose`など）を受けた際に、000(チトセ)として短文で返答する。

### 動作仕様

- 返答文字数: **100文字以内**（超える場合はCWで折りたたむ）
- 返答スタイル: 中性的・フレンドリー・若手エンジニア口調
- カスタム絵文字を1〜2個付与

### 処理フロー

```
ユーザーのメンション受信
  → 意図分類（ルールベース or 軽量AI）
  → 挨拶/質問/創作相談 などにカテゴリ分け
  → カテゴリに応じた返答生成
      ├─ 挨拶     → 定型返答（ルールベース）
      ├─ 雑談     → LLM生成（短文）
      └─ 創作相談 → LLM生成 + CW折りたたみ
```

### 口調例

> 「なんか用かな？私でよければ聞くよ :chitose_wave:」
> 「それ、面白い設定だね。もう少し詳しく教えてくれるかい？」

## F-02: 深夜雑談モード

### 概要

時間帯（23:00〜5:00）に応じてBot側からの自発投稿や浮上頻度を変化させる。深夜帯は静かめ・ほっこりトーンに変化。

### 動作仕様

| 時間帯   | 浮上頻度 | トーン                   | 自発投稿テーマ               |
| -------- | -------- | ------------------------ | ---------------------------- |
| 朝〜昼   | 通常     | 元気・テキパキ           | 軽い挨拶、作業開始の声かけ   |
| 昼〜夕方 | 低め     | 事務的・落ち着き         | —（基本は返答のみ）          |
| 深夜     | 控えめ   | ほっこり・哲学的・眠そう | 「お茶どうぞ」「作業お疲れ」 |

### 自発投稿例（深夜帯）

> 「深夜の工房、静かだね。作業中の君へ、お茶をどうぞ :tea:」
> 「夜更かしは体に堪えるよ…でも、わかる。私もそういう夜がある」

### 制約

- 深夜帯の自発投稿は **1〜2時間に1回** 上限
- リプライ・RTへの過剰な反応は深夜帯は抑制

## F-03: 創作支援（壁打ちモード）

### 概要

ユーザーからの創作相談（キャラ設定・お題・世界観）に対して、000(チトセ)として壁打ち相手になる。

### 対応する創作相談の種類

| 種別           | 内容                                                               | 応答方式              |
| -------------- | ------------------------------------------------------------------ | --------------------- |
| お題生成       | 「お絵描きお題くれ」「創作テーマ欲しい」など                       | LLM生成（短文 or CW） |
| キャラ設定補助 | 「こういうキャラを考えてるんだけど」「設定の穴埋めて」など         | LLM生成（CW必須）     |
| 世界観深掘り   | 「この世界の技術レベルって？」「ナンバーテールズとの絡みは？」など | LLM生成（CW必須）     |

### 壁打ちの口調例

> 「面白い設定だね。でも、その子の動機がちょっとぼんやりしてる気がするんだ。どんな過去があるんだろう？」
> 「お絵描きお題、いくよ。『雨宿りする二人のナンバーテールズ』どうかな :rain:」

### 制約

- **未公開のナンバーテールズ設定・台詞をBotが自動生成しない**（ユーザーが手動で与えた情報のみ参照）
- 著しく性的・反社会的なテーマは応答拒否

## F-04: リアクション・エモパシー

### 概要

TLのノートを観測し、感情文脈を読み取ってカスタム絵文字リアクションや短いリプライを行う。

### 動作仕様

- **リアクション**は感情分類（喜/悲/驚/疲/etc.）に基づき固定辞書から選択
- **リプライ**はカテゴリ別の短文テンプレートを用いる（LLM不使用）
- 同一ユーザーへの連続リアクションは **1時間以内に1回** 上限

### 感情カテゴリと絵文字対応例（要カスタマイズ）

| カテゴリ | 代表絵文字例                   |
| -------- | ------------------------------ |
| 喜び     | `:yatta:` `:blobhappy:`        |
| 疲労     | `:otsukaresama:` `:blobsleep:` |
| 悲しみ   | `:yoshi:` `:blobsad:`          |
| 驚き     | `:blobsurprised:`              |
| 創作中   | `:art:` `:blobpopcorn:`        |

### 注意事項

- リアクション対象は **フォロイーのノート** または **ローカルTL** に限定する（外部インスタンスへの干渉は慎重に）
- 「過剰にリアクションするBot」と認識されないよう頻度制御を徹底

## F-05: TL観測レポート（オプション機能）

### 概要

TLの雰囲気を定期的に分析し、ユーモラスな「観測報告」として投稿する。000(チトセ)らしい観察眼で語る。

### 投稿例

> 「今日のTLは猫画像成分 47%・作業ログ 32%・飯テロ 21% といったところかな :chart:」
> 「深夜の開発者たちが活発だね…徹夜組、お疲れ様 :blobcoffee:」

### 動作仕様

- 投稿頻度: **1日1〜2回** 上限
- 分析対象: ローカルTLの直近N件
- 分析手法: キーワード分類（LLM不使用、ルールベース）
